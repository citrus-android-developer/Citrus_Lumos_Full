# 標註刷新_實作計畫

> **For agentic workers:** 逐任務 TDD(先紅後綠),每任務獨立可測、獨立 commit。spec=[[Projects/標註刷新_計劃]](r1 收斂版,S0-S4+驗收線為權威)。

**Goal:** 讓考卷語料能安全前進——delta 補標流水線+重釘機械閘+未標率警示。

**Architecture:** 新腳本 `refresh_labels.py` 承載 delta/repin/merge/apply/signal 五子命令;母體與未標判定抽進 `retrieval_eval.py` 共用(單一實作);`build_goldset.py` 加裸跑防護;bash 週閘只做薄接線。

**Tech Stack:** python3 stdlib(零依賴家規);測試進 `scripts/test_lumos.py`(t_ 前綴+`_need_src`)。

## Global Constraints(spec 逐字)
- 評測母體=「考卷計分與 hook 實際消費的候選集合」:search=legacy(不截斷)∪ranked top10;edit=`impact --top 50` 全輸出含 pinned。
- 標註三態:已判(final∈{0,1,2})/未標(無鍵或 final null);★禁止沿用 `_labels_of`/`unl` 收斂讀法★。
- 題目凍結:只讀 goldset 既有 `search`/`edit` 陣列,★禁重呼 `edit_cases()`★;edit file 不存在→`skip:file-gone`。
- goldset 寫入恆 tmp+`os.replace` atomic;單寫者(apply 是唯一寫 labels 入口;排程只讀)。
- 一致=同值(1 vs 2=不一致);merge 前必經人放行(人跑 apply=放行動作)。
- repin rc:0=已重釘/1=有未標硬擋/2=輸入壞——本腳本權威。
- 計分路徑恆無 LLM。
