# 結構訊號補鏈D3_計劃

> 白話:這是一個**佔位 gap 節點,還沒立案實作**。想法是補鏈候選除了「節點文字有提到檔名」「架構圖鄰居有連」之外,再加一路「code 自己的耦合關係」(A 檔跟 B 檔歷史上總一起改/互相 import → 管 A 的節點可能也該管 B)。但立案當下沒有任何一筆實證 miss 需要它——照實驗先行紀律,**等巡檢撞到一筆 D1/D2 接不住的 miss 才啟動**,啟動時先重跑 PRIOR-ART 三問再進 brainstorm。

## 啟動條件(硬)

- [ ] 至少一筆實證 miss:live impact 反查顯示某節點該管某檔,而 D1(純文字)與 D2(鄰居家族)皆無訊號、結構耦合有訊號。
- 滿足後:重跑 PRIOR-ART 三問 → brainstorm → design-loop 資格判定。
