# slim-uninstall-一行卸載

公開精簡版的一行卸載入口(`slim/uninstall.sh`)。給接手者「不想要就乾淨移除」的路,不用自己猜要刪什麼——安全紀律是這支腳本的重點,比功能本身重要,見上方合約性 KEY 行。用法與 [[Systems/slim-get-一行安裝]] 對稱:`curl -fsSL <raw-url>/uninstall.sh | bash`,或裝好後直接跑 `~/.lumos-slim/uninstall.sh`。詳見 [[Projects/公開精簡版_實作計畫]] Task 6(一行安裝／卸載)、Task 8(CLAUDE.md sentinel 對稱移除)、Task 9(裁定第三次變更:對稱移除升級成對稱還原)、Task 10(★2026-07-31 端到端實測抓到真 bug:步驟改成互不阻擋、bin 比對基準改用 install.sh 寫的 manifest★)。

原本只動三個路徑(`~/.local/bin/lumos`、`~/.claude/skills/lumos-project-notes/`、`~/.lumos-slim`),每個路徑都先驗證「這真的是我們裝的東西」才動手——`~/.local/bin/lumos` 靠與 [[Systems/slim-install-安裝器]] 寫的 manifest(`~/.local/share/lumos-slim/manifest.json`)做 sha256 內容比對(找不到 manifest 才退回舊版 `~/.lumos-slim/scripts/lumos` 備援比對),`~/.lumos-slim` 靠結構特徵(含 `scripts/lumos`+`install.sh`)判斷。**第四個路徑**:執行目錄下的 `CLAUDE.md`——與 [[Systems/slim-install-安裝器]] 對稱,Task 9 把「單純挖掉」升級成「讀備份、有就還原、沒有就挖掉」:找到 `LUMOS-SLIM` sentinel 就讀出區塊內建的 `FULL-BACKUP` 標記,base64 解碼還原完整版區塊(若有)回原位置,否則單純移除;不需要額外的「這是我們裝的嗎」驗證,因為判斷依據就是 sentinel 本身存不存在(找不到=未裝,天然冪等)。

**Task 10 端到端實測抓到的真 bug(修復核心)**:`~/.lumos-slim` 只有走 `get.sh`(一行安裝)才會存在。README 也在教的另一條路——直接 clone 交付包到任意路徑、跑包內 `install.sh`——不會建立這個固定落點。舊版把①的 sha256 比對當一票否決,基準缺失就直接 `exit 2` 中止整支腳本,**④CLAUDE.md 的完整版還原完全沒機會執行**——接手者從此卸載不掉;而且舊訊息說「這可能是你自己的東西」在「基準缺失」這個情境下是誤導(其實就是本包裝的,只是找不到比對基準)。修法兩件事:①install.sh 現在會寫一份身分證 manifest(`~/.local/share/lumos-slim/manifest.json`),不依賴 `~/.lumos-slim` 存在;②四個清理步驟改成各自獨立判斷/執行,互不阻擋,最後才彙總報告、決定 rc。
