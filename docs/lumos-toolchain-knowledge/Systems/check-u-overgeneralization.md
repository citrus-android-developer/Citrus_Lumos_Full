# Check U — 全稱宣稱未綁測試（過度概化守衛）

## 守什麼

★**把單一模組的個別設計寫成系統通則**★。

**實例（2026-08-12 LandmarkMember 實證）**：`背景排程總覽` 寫「服務 disabled 時也要寫心跳、`LastStatus` 一律填 `success`」，讀起來是所有 BackgroundService 的通則——
**實際上只有 `ReconciliationSelfHealService` 這麼做**（其註解自陳「只借排程算式，不借 Enabled 骨架」），
現役的 `SecurityAnomalyMonitorService` 是 disabled 時**直接 return、完全不寫心跳**。

> ★這類最毒的地方★：不是資料錯，是**後人依樣畫葫蘆**——照著「通則」寫新服務，就長出一個跟半數既有實作不一致的東西。

另一個真陽性：`CustTransfer` / `滿額贈` 的「**折疊守衛（通則）**」——自稱通則、寫著「凡顯示/計數該表的查詢**都必須**折疊」、**零 `[test:]`**，
而節點自己就記載這條規則 2026-06-02 被漏補、**一路到 07-21 才被使用者回報**。

## 判定條件（三訊號同現）

| 訊號 | 樣式 |
|---|---|
| 分配式量詞 | `所有｜每個｜每支｜每一｜各個｜凡是｜凡｜一律` |
| 程式實體 | `Service｜Repository｜Controller｜Job｜服務｜排程｜查詢｜端點｜入口｜呼叫點｜實作｜模組｜節點｜欄位` |
| 義務語氣 | `必須｜都要｜都必須｜皆須｜應該｜一律要｜要寫｜要帶｜不可｜禁止` |

**只掃 summary 的 `KEY:` 行**（FLOW/DEP 等不在合約宣稱範圍）。

**消音三路**：行內有 `[test:]`／標了 `★DEBT★`／改寫成限定範圍語氣。
★綁了 `[test:]` 就不吵是刻意設計★——否則綁了沒獎勵，就沒人會去綁。

## 為什麼是三訊號（噪音實測，不是拍腦袋）

| 條件 | 在 LandmarkMember（30 篇 Systems / 261 條 KEY 行）的命中 | 判斷 |
|---|:--:|---|
| 只看量詞（`一律｜必須｜所有…`） | **17%**（45 行） | ❌ 抽樣多為用詞規範（「對人一律說『校正』」）與操作指示 → **會被無視的 warn** |
| 三訊號同現 | **1%**（5 行），3 條真陽性 | ✅ 採用 |

> **一個 warn 的價值取決於它會不會被關掉**。17% 的命中率等於訓練使用者忽略它，那比沒有這個檢查更糟。

## 它不做什麼

**不取代適應度函數**。

`PRIOR-ART`（2026-08-12 真搜）：世界對這類問題的成熟解是**架構適應度函數**（ArchUnit / Deptrac / go-arch-lint）——
「與其把規則畫在沒人讀的圖上，不如編成一違反就 fail build 的測試」。

Check U 只負責**問一句話**：「你這句是通則嗎？那測試呢？」
★**若真是通則，寫成一支列舉所有實例的測試會當場告訴你有沒有例外；若寫不出來，它本來就不是通則。**★

## ★通用性定位（2026-08-12 Enzo 質疑後降級）★

**Check U 不是通用機制，是「中文寫作風格的啟發式提示」。**

它靠三張**中文詞表**（分配式量詞／程式實體／義務語氣）比對——
★換一份用不同措辭的架構圖、或換成英文書寫，它會**靜默失效**且不報錯★。

對照同批的另外兩道：

| Check | 靠什麼 | 換架構圖 | 換語言棧 |
|---|---|---|---|
| **N** | 使用者自己宣告的**語法約定** | ✅ 通用 | ✅ 通用 |
| **Y** | 形狀規則 ＋ 否定詞表（**皆已 profile 化**） | ⚠ 換 lexicon | ⚠ 換 profile |
| **U** | 三張中文詞表（**未 profile 化**） | ❌ | ❌ |

> **U 抓的是「人怎麼寫」，N 抓的是「宣告要怎麼算」。** 只有後者是結構解。
> 保留 U 是因為它在本專案確實抓到真東西（折疊守衛通則），但**不應被當成可移植的機制**。
> 要移植：先跑 `lumos drift-history` 量這份架構圖有沒有這型 drift，再決定值不值得配詞表。

## 已知限制

- **語言啟發式，不是語意理解**——必有誤報（實測 5 命中中 2 條），故為 `warn` 不擋。
- **只認中文樣式**（英文架構圖需擴充樣式表）。
- **抓不到「沒用全稱語氣但實質是通則」的宣稱**——那類只有交叉審計掃得出來。
